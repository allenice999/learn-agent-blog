# JSX 与组件

## 1 JSX 本质

JSX 不是 HTML，它会被编译成 `React.createElement()` 调用（新版本是 `jsx()` 函数）。

```jsx
// 你写的
const el = <h1 className="title">Hello</h1>;

// 编译后（概念上）
const el = jsx("h1", { className: "title", children: "Hello" });
```

**关键区别**：

| HTML | JSX |
|------|-----|
| `class` | `className` |
| `for` | `htmlFor` |
| 内联样式字符串 | 对象 `style={ {color:'red'}}` |
| 可随意不闭合 | 必须闭合 `<br />` |

**JSX 里 `{}` 可以放任何 JS 表达式**（不能放语句如 `if`/`for`）：

```jsx
const name = "小明";
const el = <p>你好，{name}！{1 + 2} {name.toUpperCase()}</p>;
```

## 2 组件 = 函数

```jsx
function Welcome() {
  return <h1>Hello</h1>;
}
// 使用
<Welcome />
```

组件名**必须大写开头**，否则 React 当成 HTML 标签。

## 3 props

props 是父组件传给子组件的**只读**数据。

```jsx
function Card({ title, count = 0, children }) {
  return (
    <div className="card">
      <h2>{title}</h2>
      <p>数量: {count}</p>
      {children}   {/* 插槽 */}
    </div>
  );
}

// 使用
<Card title="苹果" count={3}>
  <button>购买</button>   {/* 这就是 children */}
</Card>
```

**要点**：
- props 解构时可以用默认值 `count = 0`
- `children` 是一个特殊 prop，代表标签之间的内容
- **永远不要修改 props**（单向数据流的基础）

在子组件中如果修改了props会怎么样？
1. 如果被修改的props数据是基本类型，修改是不生效的，不会影响父组件
2. 如果被修改的props数据是对象属性，因为React 判断"要不要重渲染"靠的是 Object.is 引用比较（浅比较），改对象属性，引用没变，React 认为"还是同一个对象，没变化"，就不会发生重新渲染，那么界面就不会更新。但是如果后面其他数据变动导致父组件发生重新渲染，那么之前没有更新的界面就会更新。这就是"幽灵更新"：数据变了，界面滞后，你完全不知道它什么时候会跳。

## 4 条件渲染

四种常见写法：

```jsx
// 1. if 提前返回
function Status({ loading, data }) {
  if (loading) return <p>加载中...</p>;
  if (!data) return <p>无数据</p>;
  return <p>{data}</p>;
}

// 2. 三元
{isLogin ? <Dashboard /> : <Login />}

// 3. 逻辑与（注意 0 的陷阱！）
{count > 0 && <span>{count}</span>}   // ✅
{count && <span>{count}</span>}       // ❌ count=0 会渲染出 "0"

// 4. 短路 + 变量
const content = list.length === 0 ? <Empty /> : <List />;
```

## 5 列表与 key

```jsx
function TodoList({ todos }) {
  return (
    <ul>
      {todos.map(todo => (
        <li key={todo.id}>{todo.text}</li>
      ))}
    </ul>
  );
}
```

**key 的规则**：
- 必须是**同级列表内唯一且稳定**的值
- **不要用数组索引**（除非列表永不增删排序）——会导致状态错位
- key 不是传给子组件的 prop，只是 React 内部用的

**为什么需要 key？** React 用它来识别哪些元素变了、增了、删了，从而最小化 DOM 操作。

```jsx
// ❌ 危险：删除第一项后，索引重新映射，input 里的值会"串位"
{todos.map((t, i) => <Row key={i} todo={t} />)}

// ✅
{todos.map(t => <Row key={t.id} todo={t} />)}
```

## 🏋️ 练习

1. 写一个 `UserCard` 组件，接收 `name`、`age`、`avatar`，用 `children` 放一个自定义按钮。
2. 写一个 `List` 组件，接收数组，空数组时显示"暂无数据"，否则用 `map` 渲染，正确使用 key。
3. 找出下面代码的 bug：

```jsx
function Bad({ items }) {
  return <div>{items.length && items.map(i => <p key={i.id}>{i.name}</p>)}</div>;
}
```

<details>
<summary>答案</summary>

当 `items.length === 0` 时，`0 && ...` 会渲染出数字 `0`。改成 `items.length > 0 && ...`。

</details>
