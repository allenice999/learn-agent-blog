## 1. ref 或 reactive 包裹的是一个对象，解构后还是响应式的吗？

**分两种：**

- 解构出的是**内层对象（Proxy）** → 仍是响应式，因为响应式附着在对象代理上。
- 解构出的是**原始值**（string/number 等） → 失去响应式，只是值快照。

一句话：**解构本身不破坏响应式，把响应式数据读成原始值才破坏。** 需要原始值也保持响应式，用 `toRef` / `toRefs`。

## 2. watch第一个参数传某个响应式对象的属性，当这个属性变化的时候，watch的回调会执行吗？
如果传入的属性是一个响应式对象，会执行；

如果传入的属性是基本类型，则不会执行，需要包裹为getter函数。

因为vue监听响应式对象变化后执行回调，是需要先收集依赖，对于watch来说，传入的值是基本类型，无法知道这个值的来源是哪里，进而无法做到监听响应式变化。

## 3. Vue中可以通过provide和inject的方式做响应数据的传递，使用inject获取到响应式数据的组件，怎么防止组件对数据直接进行修改？
在provide的时候，用readonly包裹
```js
const count = ref(0)
provide('read-only-count', readonly(count))
```
